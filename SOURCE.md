# Data source and attribution

This project downloads T20 International ball-by-ball match data from **Cricsheet**.

- Project: Cricsheet
- Website: https://cricsheet.org/
- Download page: https://cricsheet.org/downloads/
- Archive used by this project: https://cricsheet.org/downloads/t20s_json.zip
- Format: JSON

The training script filters the downloaded archive to men's T20 internationals and creates derived machine-learning features locally.

Cricsheet describes JSON as its official/main match-data format. See the format documentation at https://cricsheet.org/format/.
